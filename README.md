## 조이스틱 기반 2축 서보 제어 (팬 방향 조절)

아날로그 조이스틱으로 서보모터 2개(수평/수직)를 구동해 팬의 좌우·상하 방향을 조절하고, 버튼으로 자동 스윙 모드를 토글하는 기능을 구현했다.

### 구현 내용

- **ADC 입력 처리** ([joystick.c](joystick.c)): 조이스틱 X/Y축을 ATmega128A ADC(10bit)로 읽어 값을 얻는다. 매 루프마다 채널을 바꿔가며 폴링 방식으로 변환한다.
- **데드존 + 비례 속도 제어**: 중앙값(512) 기준 ±40 이내는 무시(데드존)하고, 중앙에서 멀어질수록 이동 스텝(`step`)이 커지도록 계산해 조이스틱을 세게 기울일수록 서보가 더 빠르게 움직인다. 스텝 상한(`SERVO_MAX_STEP`)으로 급격한 튐을 방지했다.
- **2축 서보 PWM 출력** ([servo.c](servo.c)): Timer1(OC1B, PB6)로 수평 서보, Timer3(OC3A, PE3)로 수직 서보를 각각 독립 제어한다. Fast PWM(ICR=4999, 50Hz)로 0°~180°를 듀티 125~625 범위에 매핑했다.
- **버튼 토글 → 자동 스윙 모드** ([button.c](button.c), [main.c](main.c)): 버튼 2개(수평/수직)를 소프트웨어 디바운스로 처리해 누를 때마다 해당 축의 자동 모드를 on/off. 자동 모드 진입 시 조이스틱 입력은 무시되고, 서보가 0°↔180° 사이를 왕복하며 스캔하듯 자동으로 스윙한다.
- **주기 실행**: 메인 루프에서 `system_millis` 기반 타이머로 20ms(`SERVO_UPDATE_INTERVAL_MS`)마다 한 번씩만 서보 갱신 로직을 실행해, 서보 응답 속도와 부드러움을 맞추면서 다른 태스크(센서 읽기, FND 표시 등)와 논블로킹으로 병렬 동작하게 했다.

### 동작 흐름

```
조이스틱 X/Y (ADC) ─┐
                    ├─ 데드존 판정 → 비례 step 계산 → Servo_Move*(step)
버튼(수평/수직) ─────┘         │
      │ (토글)                 ↓
      └─ Auto 모드 ON → Servo_UpdateAuto*() : 0°↔180° 자동 왕복
                                │
                                ↓
                    Servo_Apply() → OCR1B / OCR3A (PWM duty) → 서보모터 2개 회전
```

### 핵심 로직 요약

- 조이스틱 미조작(오토 모드 아님) 시: `Joystick_UpdateServo()`가 X→좌우(수평), Y→상하(수직) 서보를 각각 독립 제어
- 버튼 1(`BUTTON_ON`, PG2): 수평 자동 스윙 토글
- 버튼 2(`BUTTON_OFF`, PG3): 수직 자동 스윙 토글
- 두 축 모두 각도 범위를 0°(듀티 125) ~ 180°(듀티 625)로 클램핑해 서보 하드웨어 리밋 보호
